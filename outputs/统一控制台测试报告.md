## 5. 关键行为验证（证据类型）

1. **真实副作用**：读写用例检查临时目录中的文件内容与 SHA256；read 模式下的写/命令尝试零副作用；exec 越界写在平台上被沙箱拒绝（哨兵文件保持 unchanged）。
2. **取消语义**：等锁阶段取消 → 模型 0 调用、目标文件不出现；运行中撤权 → 记录 cancelled、无新增变更。
3. **提交失败语义**：并发外部编辑触发版本冲突 → 目标文件保持外部内容、任务状态 failed、变更清单保留冲突原因。
4. **team 漂移**：只读步骤的输入文件被团队外修改 → retry 拒绝复用（轮次保持 1）；同团队后续合法写入 → 不误报。
5. **HTTP 一致性**：QQ 与 HTTP 走同一 `prepare/resume`；scope 缺失一律 403；跨归属与不存在返回同一 404；幂等键避免重复调用。
6. **配置迁移**：旧只读根仅管理员；新式 roots 生效并列出被忽略的旧字段；worker>1 与 `cross_process_lock: true` 都被拒绝。
7. **权限边界（R01–R06）**：exec 在**真实 Seatbelt** 下读不到任意位置的 `.env*`/密钥/受保护子树（伪造标记不出现在 stdout），但仍能正常读写工作区与加载解释器；`list`/`search` 对每个后代路径复查最具体 ACL（未授权的 `private/memo.txt` 不出现，同目录的 `ok.txt` 正常返回）；备份父链指向外部时**取消覆盖**且目标内容不变；父目录在检查后被替换（确定性 hook）时 read/search/commit 全部不越界；`read max_bytes=3` 之后修改 6 字节文件成功（无假冲突），文件真的变化时仍拒绝。

## 9. 已知限制与偶发项

| 项 | 说明 |
|---|---|
| Seatbelt 正则能力 | 多分支 `(a\|b\|c)` 组会静默失配，敏感规则必须"一形态一条规则"；新增敏感名必须同时改 `app/security/paths.py` 的清单，否则会出现"broker 拒绝、exec 能读"的缝隙 |
| exec 内元数据可见 | profile 允许 `file-read-metadata`（解释器与目录遍历必需），exec 内 `ls` 能看到敏感/未授权文件的**名字**，读不到内容；与 broker 的隐藏行为有可见性差异 |
| 单文件版本上限 | 超过 `safeopen.version_read_limit()`（默认 8MiB）时 `read` 明确失败；可用 `safeopen.set_version_read_limit()` 调整（进程级） |
| `os.scandir(fd)` | `DirEntry` 不能按路径 `stat`，目录项元数据统一走 `SafeRoot.lstat(dir_fd)` |
| 偶发时序失败 | `tests/test_team_runner.py::test_workflow_timeout_stops_team` 在负载高时可能抖动（本轮出现 1 次，随后单测 3 次与多轮全量均通过）；该用例使用 0.2s 的整体超时，建议后续改为轮询等待或加宽计时余量 |
